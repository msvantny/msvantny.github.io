# msvantny.github.io

My professional and academic website, presenting my work in thermography, infrared nondestructive testing and temperature measurement.

## Website structure

- **Research** — selected research topics and their practical applications.
- **Projects** — funded research projects and GitHub repositories.
- **Publications** — recent scientific articles and links to publication records.
- **Conferences** — organised events and conference contributions.
- **Videos** — research demonstrations from my YouTube playlist.
- **About & Contact** — professional background, affiliation and contact details.

## Technology

The website is built with **HTML, CSS and JavaScript** and hosted on **GitHub Pages**. Selected content is updated from public ORCID records, a YouTube playlist and conference records maintained in Google Sheets.

## Purpose and development

This website serves both as my professional profile and as a practical experiment with AI-assisted website development.

The implementation was created primarily by **OpenAI Codex**, following my instructions and feedback. I provided the research materials, defined the content and structure, and reviewed the results.

The project explores how AI tools can help build and maintain a website hosted on GitHub Pages, including external data integrations and automated content updates.
